# Client logos

One folder per client. Each folder holds:

| File | What it is |
|---|---|
| `<name>-original.*` | The file exactly as supplied. Never edited. |
| `<name>-hq-source.png` | Higher-quality transparent logo found online (where one existed). Sources below. |
| `<name>-256.png` | Trimmed of empty margin, longest side 256 px (thumbnails). |
| `<name>-512.png` | Same, 512 px (cards, the 3D orbit). |
| `<name>-1024.png` | Same, 1024 px (large display). |

Smaller originals are enlarged in 2x steps with a light sharpen. That keeps edges crisp but cannot add detail that was never there, so
`burger-king`, `prezien`, `applebees`, `subway`, `taco-bell`, `kababji` and `hs-store` (all under 260 px) will always be softer than a vector logo.
Send SVG or high-resolution versions of those and drop them in as the new `-original`.

## Where the higher-quality logos came from

| Client | Source |
|---|---|
| kout-food-group | koutfoodgroup.com: the reversed-out artwork (2339 px), recoloured to the brand red and ink |
| burger-king | Wikimedia Commons, `Burger King 2020.svg`, rendered at 1280 px |
| pizza-hut | Wikimedia Commons, `Pizza Hut 2025.svg`, rendered at 1280 px |
| subway | Wikimedia Commons, `Subway 2016 logo.svg`, rendered at 1280 px |
| taco-bell | Wikipedia, `Taco Bell 2023.svg`, rendered at 1280 px |
| applebees | Wikipedia, `AB Brand Refresh Logo R.svg`, rendered at 1280 px |
| euaa | Wikimedia Commons, `EUAA Logo.png`, rendered at 1280 px |

No better public version was found for speedy-bunny, almaviva-de-belgique, kababji, prezien, hs-store or tellgo.
For those the supplied file is kept, with the white background cut out so the edges are transparent (tellgo is a full-bleed purple tile and is unchanged).
